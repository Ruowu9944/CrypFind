# CrypFind v1.0.0

Initial public release of the pretraining-dataset construction and quality-control code accompanying CrypFind.

Included: candidate quality filtering, UniRef50 representative selection, structure retrieval helpers, paired graph construction, graph schema/contact audits, corrected RMSD/mapping QC, small examples, aggregate statistics, and figure assets.

Not included: full AlphaFold inputs, 365,221 graph tensors, large per-sample tables, model implementation/training, checkpoints, benchmarks, docking, or molecular dynamics. See `DATASET.md` for external-data requirements and `MANIFEST.tsv` for provenance.
